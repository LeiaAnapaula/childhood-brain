# Retro: Which childhood is yours, 2026-09-27 build

Generated by /retro after the hackathon ship. Two Claude sessions built this in one afternoon (souling-67: quiz, server, generator, evals harness; apple-2f: founders evals, gbrain wiring, review, QA, ship). Three lessons, each with the evidence and the rule that follows.

## 1. The brain's identity stamp breaks on a volume remount; repair it, never reinit

The live PGLite brain refused every page ("filesystem device identifier changed while the other checkout identity fields still match") because `~/.gbrain/content/<brain>/default/.gbrain-owner.json` recorded device 16777230 at 14:28 and the same volume reported 16777231 by 16:40. The peer worked around it with a scratch brain, which meant the judge's brain had zero pages. The fix is two commands and keeps the data:

```
gbrain sources writer transfer prepare default --brain host --self-transfer --admin-intent writer_transfer_prepare --expected-state <admin_state from writer status --json>
gbrain sources writer transfer accept  default --brain host --self-transfer --path <local_path> --expected-epoch <owner_epoch> --manifest <digest> --admin-intent writer_transfer_accept --expected-state <fresh admin_state>
```

Rule: when `gbrain import` skips every file, read `gbrain sources writer status default --json` before touching anything. A scratch brain hides the problem from the person who has to demo.

## 2. Every wikilink needs a page, and the 25 hand-written childhoods are the taste

`generate.ts` wrote 100 childhoods linking to `[[parents/x]]`, `[[schools/x]]`, `[[events/x]]` that did not exist, and without an API key the fragments were seed sentences glued together. Judges search by seed words ("translator grandparent win"); the hit that reads well is `live-006`, one of the 25 from live.html, not a generated page. `scripts/build-live-pages.ts` now writes the 38 seed and base pages plus the 25 repertoire childhoods, and the 100 were regenerated with claude-sonnet-5.

Rule: the corpus is only as good as its worst page; run the generator with the key, and keep the hand-written 25 as the anchor set the search should surface first.

## 3. The seven picks carry the signal; the template text throws it away

On the four founders with names removed, Claude ranked them above 16 synthetic childhoods from the seven picks alone (AUC 0.86 Haiku, 0.88 Opus, 0.91 Fable), but from the prototype's matched fragment the ranking fell to chance (0.26 to 0.66). The matcher also sends Altman and Zuckerberg to the same childhood (childhood-001, 4/7 overlap each). Held-out recall on founders: prototype 16.7% = base rate; Opus 37.5%.

Rule: generate the fragment from the picks (the CEO review's change 2), keep the repertoire as examples, and make the human lineup (`bun run lineup`, 20 people, bar 60% pick their own) the number that gates the next feature.
