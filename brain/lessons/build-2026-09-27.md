# Lessons from the 2026-09-27 childhood-brain build

Three lessons from shipping "Which childhood is yours" with gbrain as the memory. Full retro in docs/retro.md.

## Repair the brain's identity stamp, never reinit
When `gbrain import` skips every file with "filesystem device identifier changed", the owner stamp in `.gbrain-owner.json` is stale after a volume remount. Run `gbrain sources writer status default --json`, then `transfer prepare` and `transfer accept` with `--self-transfer`. Data is kept. A scratch brain hides the problem from whoever has to demo.

## Every wikilink needs a page
Childhood pages link to [[parents/storm]], [[schools/elite]], [[events/translator]], [[bases/lima-peru]]. Those pages must exist or the graph is dead ends. scripts/build-live-pages.ts writes them from live.html; generate.ts needs ANTHROPIC_API_KEY or fragments are seed text glued together.

## The seven picks carry the signal; template text throws it away
On four founders with names removed, Claude ranks them above synthetic childhoods from the picks alone (AUC 0.86 to 0.91) but not from the matched template fragment (0.26 to 0.66). Generate the fragment from the picks; keep the 25 hand-written childhoods as examples; gate features on the human lineup (bun run lineup).
